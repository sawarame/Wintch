# UI画面・振る舞い契約 (UI Contracts): Wintch MVP

**Feature**: `001-window-switcher-mvp`  
**Created**: 2026-11-13  
**Purpose**: スイッチャーUI、メニューバー、設定画面、権限誘導画面のコンポーネント構造と画面表示上のルールを定義します。

---

## 1. メニューバー常駐（`MenuBarExtra` / `LSUIElement`）
- アプリケーションの `Info.plist` に `LSUIElement = YES` を設定し、Dock にアイコンを表示しない。
- メニューバーに表示するメニュー項目は以下に限定する（過剰機能の排除）。
  1. **設定を開く...**（ショートカット目安: `⌘,`）: 設定画面ウィンドウを最前面に表示する。
  2. **区切り線**
  3. **Wintch を終了**（ショートカット目安: `⌘Q`）: アプリケーションを安全に終了する。
- （※アクセシビリティ権限が未許可の状態では、メニューバーアイコンのバッジやメニュー上部メッセージで「アクセシビリティ権限が必要です」を選択可能にし、クリックで権限誘導画面を再表示できるようにする）

---

## 2. フローティングスイッチャーパネル（`SwitcherPanel` + `SwitcherListView`）
- **表示位置・ウィンドウ特性**:
  - 現在アクティブなスクリーン（マウスカーソルがあるディスプレイまたはメインスクリーン）の中央に配置。
  - AppKit `NSPanel` の `.nonactivatingPanel` を使用し、表示しても他アプリのアクティブ状態を奪わない。
  - `.canJoinAllSpaces` および `.fullScreenAuxiliary` を設定し、どの仮想デスクトップ・フルスクリーンアプリ上でも最前面（`.floating` / `.popUpMenu` 相当）に表示される。
  - パネル外をクリックしてフォーカスを失った場合、切り替えを実行せずに閉じる（キャンセル）。
- **リストアイテムの要素（縦型リスト）**:
  - **アプリアイコン**: 固定サイズ（例: 24x24 pt）
  - **アプリケーション名**: 1行表示（強調）
  - **ウィンドウタイトル**: 1行表示（`lineLimit(1)` + 末尾省略 `truncationMode(.tail)`）。タイトルが空の場合は「(タイトルなし)」等の控えめな補助表示を行う。
  - サムネイル画像、閉じるボタン、最小化ボタン、スペース番号バッジ、検索バーは一切配置しない。
- **選択状態の表現**:
  - `selectedIndex` に一致する行を明確なハイライト背景色で強調表示する。
  - リスト項目が多い場合は最大表示高さ（例: 画面高さの60%程度）でスクロール可能とし、選択行変更時に `ScrollViewReader` で自動追従する。

---

## 3. アクセシビリティ権限誘導画面（`PermissionGuideView`）
- **トリガー**:
  - アプリ起動時にアクセシビリティ権限が `.denied` の場合、または常駐中に権限が剥奪された場合に自動表示される。
- **表示要素**:
  1. タイトルとアイコン（例：「アクセシビリティ権限の許可が必要です」）
  2. 許可が必要な簡潔な理由（ウィンドウ切り替えとショートカット検知にのみ使用し、画面収録権限は使用しない旨を明記）
  3. 手順の3ステップ説明（① 下のボタンでシステム設定を開く → ② リスト内の「Wintch」のスイッチをオンにする → ③ 自動的に切り替え機能が有効になります）
  4. プライマリアクションボタン：「システム設定を開く」（`openAccessibilitySettings()` を呼び出す）
- **自動遷移**:
  - バックグラウンドで権限が `.granted` に変わったことを検知したら、誘導画面を自動的に閉じ、グローバルショートカット監視とウィンドウ監視を開始する。

---

## 4. 設定画面（`SettingsView`）
- **表示要素（最小限の2セクション構成）**:
  1. **ショートカット設定**:
     - 修飾キー選択ピッカー：`Option (⌥)` / `Control (⌃)` / `Command (⌘)`
     - トリガーキー選択ピッカー：`Tab (⇥)` / `Space` / `` ` (バッククォート) `` / `\ (バックスラッシュ)`
     - 現在の組み合わせプレビュー表示（例: `⌥ + Tab` / 逆順: `⌥ + Shift + Tab`）
     - `Command + Tab` 選択時の競合注意テキスト表示
  2. **一般設定**:
     - トグルスイッチ：「ログイン時に自動起動」（`LaunchAtLoginServicing` と同期）
     - エラー発生時のインラインエラー表示（`.app` バンドル未実行時などOSからエラーが返った場合）
  3. **システム状態（情報表示のみ）**:
     - アクセシビリティ権限のステータス表示（許可済み / 未許可＋設定を開くリンク）
