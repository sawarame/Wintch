# 機能仕様書: アクセシビリティ権限誘導ダイアログの説明文全文表示修正

**Feature Branch**: `016-fix-permission-guide-text`

**Created**: 2026-11-17

**Status**: Draft

**Related Issue**: [#19](https://github.com/sawarame/Wintch/issues/19)

**Input**: User description: "アクセシビリティ権限の許可のダイアルログの説明「リスト型および検索ランチャでは....」の箇所が途中で途切れてしまっているので、全体が見えるように修正してほしい（Issue #19）"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - アクセシビリティ権限誘導ダイアログの説明文を途切れなく全文読める (Priority: P1)

ユーザーは、アクセシビリティ権限が未許可の状態で表示される権限誘導ダイアログを開いた際、画面下部の補足説明文（「※ リスト型および検索ランチャーでは「画面収録」権限を使用しません（キャプチャ表示型を選択した場合のみ任意で使用します）。」）をはじめとするすべての案内テキストが省略記号（`...`）で途切れることなく全文表示され、アプリが要求する権限の範囲を正確に理解できることを期待する。

**Why this priority**: Issue #19 で報告された直接の不具合であり、プライバシー方針（「リスト型および検索ランチャーでは画面収録権限を使用しない」こと）を説明する重要な注記が途中で途切れて読めない状態では、ユーザーが権限許可に不安や誤解を抱く可能性があるため。

**Independent Test**: アクセシビリティ権限が未許可の状態で権限誘導ダイアログを表示した際、補足説明文を含むすべての案内テキストが省略や見切れなく全文表示され、かつ操作ボタン（「再確認」「システム設定を開く」）が正常に表示・操作できることで検証できる。

**Acceptance Scenarios**:

1. **Given** アクセシビリティ権限が未許可の状態で権限誘導ダイアログが表示された状態, **When** ダイアログ内のテキスト全体を確認する, **Then** 補足説明「※ リスト型および検索ランチャーでは「画面収録」権限を使用しません（キャプチャ表示型を選択した場合のみ任意で使用します）。」を含むすべての文言が省略記号（`...`）や上下見切れなしで全文表示される。
2. **Given** 開発版（アプリ名 `Wintch_dev`）または配布版（アプリ名 `Wintch`）のいずれかで権限誘導ダイアログが表示された状態, **When** 許可手順 1〜3 および補足説明を確認する, **Then** いずれのビルド構成でも手順文言および補足説明がすべて折り返し・収容され、他の UI 要素（ボタンや手順ボックス）と重なったり欠けたりしない。

---

### User Story 2 - ダイアログ内の見出し・手順・操作ボタンとのレイアウト調和を保つ (Priority: P2)

ユーザーは、説明文の全文表示対応後も、ダイアログ全体の余白・視認性・操作ボタンへのアクセス性が損なわれず、見出しから手順・補足説明・操作ボタンまで自然な順序で快適に確認・操作できることを期待する。

**Why this priority**: テキストを折り返して全文表示する際にダイアログの高さや余白が不足すると、別の要素（手順リストやボタン）が押し潰されたり見切れたりする二次不具合につながるため。

**Independent Test**: 権限誘導ダイアログを開いた状態で、タイトル・見出し・手順 1〜3・補足説明・下部ボタン（「再確認」「システム設定を開く」）のすべてが十分な余白を保って視認・クリック可能であることで検証できる。

**Acceptance Scenarios**:

1. **Given** 権限誘導ダイアログが画面上に表示されている状態, **When** ダイアログの上端から下端まで各要素の配置と余白を確認する, **Then** どの要素もウィンドウ枠からはみ出したり重なったりせず、「再確認」および「システム設定を開く」ボタンを即座にクリックできる。

---

### Edge Cases

- **複数行へ折り返された場合の高さ確保**: 補足説明文が 2 行以上に折り返された場合でも、ダイアログ全体の高さが内容に合わせて確保され、上下の余白やボタン行が切り詰められないこと。
- **アプリ名の長さの違い（配布版 `Wintch` vs 開発版 `Wintch_dev`）**: ステップ 2 の手順文言に含まれるアプリ表示名が変わっても、手順文言が途切れたりレイアウトが崩れたりしないこと。
- **システムフォントサイズや表示倍率の違い**: 標準的な macOS 表示環境においてテキストが予期せず 1 行に圧縮・省略されないこと。
- **ウィンドウの再表示**: 一度ダイアログを閉じた後にメニューバー等から再度開いた場合も、正しいサイズ・レイアウトで全文が表示されること。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: システムは、アクセシビリティ権限誘導ダイアログ内の補足説明文（「※ リスト型および検索ランチャーでは「画面収録」権限を使用しません（キャプチャ表示型を選択した場合のみ任意で使用します）。」）を、省略記号による切り詰めなしで全文表示しなければならない（MUST）。
- **FR-002**: システムは、権限誘導ダイアログ内の見出し・サブタイトル・許可手順（ステップ 1〜3）のすべての文言についても、複数行折り返しを含めて見切れや省略が発生しないよう収容しなければならない（MUST）。
- **FR-003**: システムは、テキスト全文の折り返し表示に必要な高さをダイアログおよびウィンドウ側で確保し、各要素や操作ボタン（「再確認」「システム設定を開く」）の重なり・はみ出し・上下見切れを防止しなければならない（MUST）。
- **FR-004**: システムは、従来の機能（最前面表示、再確認アクション、システム設定誘導アクション、権限許可検知時の自動閉鎖および監視再開）をそのまま維持しなければならない（MUST）。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 権限誘導ダイアログを表示した際、補足説明文を含む全テキストにおいて末尾や途中の省略記号（`...`）および見切れが 0 箇所である。
- **SC-002**: 配布版（`Wintch`）および開発版（`Wintch_dev`）の双方の表示文字列条件下で、権限誘導ダイアログ内のすべての文字・ボタンがウィンドウ内におさまり、操作可能率が 100% である。
- **SC-003**: 本修正後も既存の自動テスト全件がパスし、アプリビルドがエラーなく完了する。

## Assumptions

- 補足説明の文言自体（「※ リスト型および検索ランチャーでは「画面収録」権限を使用しません（キャプチャ表示型を選択した場合のみ任意で使用します）。」）は、Wintch 憲章 v2.0.0 の「最小権限およびオプトインの原則」に適合した内容であるため、文言の削減や変更ではなく、レイアウトおよびウィンドウサイズの適切な確保により全文を表示する。
- ダイアログの横幅は既存のバランス（460pt 基準）を維持しつつ、必要な縦方向スペースを内容に応じて十分に確保する前提とする。
