# 検証ガイド (Quickstart): Chrome 複数ウィンドウ切り替え修正のビルドとテスト

**Feature**: `012-fix-chrome-window-switch` | **Date**: 2026-11-17

## 1. 自動テスト（Swift Testing）による検証

実装・修正後に以下のコマンドで全テストを実行し、既存テストおよび新規追加テストが 100% 合格することを確認する。

```bash
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test
```

### 確認対象の主要テストスイート
- `WindowMenuPairingTests`:
  - 元タイトル自体に `…` / `...` を含む場合の中央・多重省略タイトル照合
  - オフスクリーン横長補助 CGWindow（例: `1344x378`）より本物の別スペースウィンドウが優先ペアリングされること
  - 別スペース遷移時（`preferUnchecked: true`）に同名タイトルのチェック無し項目が優先選択されること
- `WindowCaptureAndMatchingTests`:
  - 別スペースに同矩形の通常ウィンドウが存在する状態で、スペース移動や全体スキャン時に別スペース側の `CachedAXWindow` が誤削除されないこと
  - 同一スペース上のタブ切り替え時（独立生存 CGWindow なし）には旧タブが整理されること
  - メニューキャッシュ鮮度判定（TTL 超過時は再取得扱い）およびアクティブ化制御計画の検証

## 2. `.app` バンドルビルドおよび手動実機検証

```bash
# Debug ビルドと起動
./scripts/build-app.sh
open .build/Wintch.app
```

### 実機検証シナリオ（Google Chrome 複数ウィンドウ）
1. **通常サイズ・同位置での複数スペース配置**:
   - Space 1 と Space 2 にそれぞれ Chrome の通常ウィンドウ（異なるページ）を同じ位置・サイズで開く。
   - Space 2 から通常スイッチャー（キャプチャ表示型）および検索ランチャーを開き、Space 1 の Chrome ウィンドウを選択する。
   - **期待結果**: Space 1 の対象 Chrome ウィンドウへ確実に切り替わること。
2. **アドレスバー予測変換入力後の別スペース切り替え**:
   - Chrome のアドレスバーに入力して予測変換ポップアップを出した後に別スペースへ移動し、Wintch のキャプチャ表示型スイッチャーを開く。
   - **期待結果**: 本物の Chrome ウィンドウのサムネイル／識別子が予測変換用裏方ウィンドウに奪われず、選択時に正しい Chrome ウィンドウへ遷移すること。
3. **省略記号を含む長いタイトル・同名タイトルの切り替え**:
   - ページタイトルに `…` を含むページや、同じ「新しいタブ」を複数スペースで開いた状態から別スペースのウィンドウを選択する。
   - **期待結果**: 現在スペース側ではなく選択した別スペース側のウィンドウへ切り替わること。
