# クイックスタート・検証ガイド: ウィンドウ 0 件時の検索ランチャー起動対応

**Feature**: `010-launcher-without-windows` | **Date**: 2026-11-16

## 1. 前提条件

- macOS 14.0 (Sonoma) 以降
- Xcode（Swift 6.0 / Swift Testing マクロ実行用）
- 実機動作確認時は Wintch に対するアクセシビリティ権限の許可が必要（画面収録権限は不要）

## 2. 自動テストによる検証

ユニットテスト一式を実行し、ドメイン層（`LauncherEmptyState`）および ViewModel 層（`SwitcherViewModel` の 0 件起動・空状態遷移・最後のウィンドウ終了維持・通常スイッチャー非起動維持）がすべて合格することを確認する。

```bash
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test
```

期待結果：
- 既存の全テストに加えて、`010-launcher-without-windows` で追加・更新したテストがすべて成功し、失敗・スキップがないこと。

## 3. アプリバンドルのビルドと実機動作確認

```bash
./scripts/build-app.sh
open .build/Wintch.app
```

> **注意**: 再ビルド後、macOS の署名識別変化によりアクセシビリティ権限の再認識が必要な場合は、「システム設定 ＞ プライバシーとセキュリティ ＞ アクセシビリティ」から Wintch を一度削除して再登録する。

### 手動検証シナリオ

1. **ウィンドウ 0 件での検索ランチャー起動とアプリ起動（User Story 1）**
   - 開いているアプリウィンドウをすべて閉じる（Finder ウィンドウも閉じる）。
   - `Option + Space`（または設定済みのランチャーショートカット）を押す。
   - **確認**: パネルが画面中央に即座に表示され、検索欄にフォーカスが当たり、リスト領域に「開いているウィンドウがありません（アプリ名を入力して起動）」が表示される。
   - `"safari"` や `"メモ"` などの文字を入力する。
   - **確認**: パネル上端位置が動かず下に候補が展開され、「アプリを起動」見出しの下に一致アプリが表示され、先頭項目が選択される。`Enter` またはクリックで対象アプリが起動しパネルが閉じる。

2. **通常スイッチャーとの役割分離（User Story 2）**
   - 再びすべてのウィンドウを閉じて 0 件にする。
   - `Option + Tab`（通常スイッチャー）を押す。
   - **確認**: 通常スイッチャーパネルは表示されない。

3. **検索ランチャー上で最後の 1 枚のウィンドウを閉じた後の継続利用（User Story 2）**
   - 任意のウィンドウを 1 枚だけ開いた状態で `Option + Space` でランチャーを開く。
   - そのウィンドウを選択した状態で `Option + Q`（修飾キー + `Q`）を押して閉じる。
   - **確認**: ウィンドウが 0 件になってもランチャーパネルは閉じずに開いたまま維持され、「開いているウィンドウがありません（アプリ名を入力して起動）」へ切り替わる。そのまま別のアプリ名を入力して起動できる。

4. **一致 0 件・文字クリア・キャンセル（User Story 1 & 2）**
   - ウィンドウ 0 件でランチャーを開き、存在しない文字列（例：`"zzzzzz"`）を入力する。
   - **確認**: 「一致するアプリがありません」が表示され、`Enter` や矢印キーで誤動作せずパネルが維持される。
   - 検索欄の文字をすべて消すと「開いているウィンドウがありません（アプリ名を入力して起動）」へ戻り、`Esc` または `Option + Space` でパネルが閉じる。
