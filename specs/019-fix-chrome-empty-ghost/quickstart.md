# クイックスタート・検証ガイド: Chrome等のタブ全閉によるウィンドウ閉鎖後に空の表示が残る問題の修正

**Feature**: `019-fix-chrome-empty-ghost` | **Date**: 2026-11-18

## 1. 自動テストの実行手順

リポジトリルート（または作業用 worktree ルート）で以下のコマンドを実行し、既存の全テストおよび今回追加したユニットテストがすべて合格することを確認する。

```bash
swift test
```

> Command Line Tools 環境でマクロエラーが出る場合:
> ```bash
> DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test
> ```

## 2. アプリケーションバンドルのビルド検証

```bash
./scripts/build-app.sh
```

`.build/Wintch.app` がエラーなく生成・署名されることを確認する。

## 3. 主要な検証シナリオ

1. **Chrome の全タブ・全ウィンドウ閉鎖時のゴースト非表示確認（SC-001）**
   - Google Chrome で開いているタブをすべて閉じてウィンドウを閉鎖する（Chrome アプリ自体は起動中）。
   - 閉鎖直後（2 秒以内）および数秒後に通常スイッチャー（リスト型・キャプチャ表示型）と検索ランチャーを起動し、`Google Chrome (タイトルなし)` や真っ白なプレビューが一切表示されないことを確認する。
2. **複数ウィンドウのうち 1 枚を閉じた際の残存ウィンドウ整合性確認（SC-002）**
   - Google Chrome で 2 枚のウィンドウを開き、片方のタブをすべて閉じてウィンドウを閉じる。
   - スイッチャーおよびランチャーに残りの 1 枚のみが表示され、閉じたウィンドウが空き殻 `CGWindow` に乗り換えて残らないことを確認する。
3. **別スペースの「新しいタブ」ウィンドウ等のタイトル補完と遷移確認（SC-003）**
   - 別操作スペース（フルスクリーン含む）で「新しいタブ」を開いた Chrome ウィンドウがある状態でスイッチャーを起動し、`(タイトルなし)` ではなく「新しいタブ」として表示され、選択時にそのスペースへ切り替わることを確認する。
