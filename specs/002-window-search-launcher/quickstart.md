# クイックスタート・検証ガイド (Quickstart): ウィンドウ検索ランチャーモード

**Feature**: `002-window-search-launcher`  
**Date**: 2026-11-13

## 1. ビルドとユニットテストの実行

```bash
# ユニットテストの実行
swift test

# ※ SwiftPM のキャッシュにより TestingMacros 関連エラーが出た場合
swift package clean && swift test
```

期待結果：
- 既存の 7 テストスイートに加え、新規追加されるランチャー用テスト（ファジー検索・ハイライト範囲・ショートカット競合検証・ランチャーショートカット永続化・`SwitcherViewModel` / `SettingsViewModel` 状態遷移）がすべてパスすること。

---

## 2. `.app` バンドルのビルドと起動

```bash
./scripts/build-app.sh
open .build/Wintch.app
```

> [!NOTE]
> 再ビルド後にアドホック署名ハッシュが変わった場合は、「システム設定 ＞ プライバシーとセキュリティ ＞ アクセシビリティ」から一度「Wintch」を `−` で削除し、`＋` で `.build/Wintch.app` を再追加してから起動してください。

## 3. エンドツーエンド手動検証シナリオ

### シナリオ A: ランチャー起動・ファジー検索・ハイライト・切り替え (US1)
1. Google Chrome や Visual Studio Code、Finder など複数アプリ・複数ウィンドウを開いた状態にする。
2. `Option + Space` を押してキーを離す。
   - **確認**: パネルが閉じずに開いたまま維持され、上部の検索欄にフォーカスが当たり、2番目のウィンドウが初期選択されていること。
3. `"vsc"` または `"chr git"` と入力する。
   - **確認**: リアルタイムに候補が絞り込まれ、先頭（1番目）が選択状態になり、一致した文字が太字・ハイライト表示されること。
4. `↓` / `↑` および `Ctrl + N` / `Ctrl + P` で選択を上下に移動し、`Enter` を押す。
   - **確認**: 選択したウィンドウ（別操作スペース含む）が最前面にアクティブ化され、パネルが閉じること。

### シナリオ B: 日本語 IME 変換の優先動作 (US1)
1. タイトルに日本語を含むウィンドウ（例：「設定」「メモ」や日本語タイトルのブラウザタブ）を開いておく。
2. `Option + Space` でランチャーを開き、日本語 IME をオンにして `"せってい"` → 変換候補選択（`↓`）→ 変換確定（`Enter`）を行う。
   - **確認**: 変換中の `↓` や `Enter` でウィンドウ一覧が誤動作せず、IME の確定が完了した後に再度 `Enter` を押すことで目的のウィンドウへ切り替わること。
3. 変換中に `Esc` を押した際はまず変換がキャンセルされ、未変換状態で `Esc` を押すとランチャーが閉じて直前のアプリへフォーカスが戻ること。

### シナリオ C: 上端固定リサイズ・0件表示・モード共存 (US1 / US2)
1. 10個以上のウィンドウを開いた状態で `Option + Space` を押し、パネル上端の位置を目視確認する。
2. 一致数が減るように文字を入力し、さらに一致しない文字列 `"zzzzqqq"` を入力する。
   - **確認**: パネル上端（検索ボックス）が上下に動かず下端のみ縮むこと、0件時に「一致するウィンドウがありません」が表示されること、`Enter` を押しても誤切り替えしないこと。
3. ランチャー表示中に `Option + Tab` を押しても通常モードへ切り替わらないこと、また `Option + Space` 再押下でランチャーが閉じること。
4. パネルを閉じた後、`Option + Tab` と `Option + Shift + Tab` が従来通り通常スイッチャー（順方向・逆方向）として動作すること。

### シナリオ D: 設定画面ショートカットレコーダーと双方向競合防止 (US3)
1. メニューバーから「設定を開く...」を選択する。
2. ランチャー設定のレコーダーをクリックし、修飾キーなしの `"K"` や `"Shift + K"` を入力する。
   - **確認**: 登録が拒否され、修飾キー必須エラーが表示されること。
3. レコーダーに通常スイッチャーと同じ `"Option + Tab"` または `"Option + Shift + Tab"` を入力する。
   - **確認**: 重複エラーが表示され、ランチャー設定が変更されないこと。
4. レコーダーに `"Control + Space"` を入力して確定し、今度は通常スイッチャーの Picker を `Control` + `Space` に変更しようとする。
   - **確認**: 通常スイッチャー側でも重複エラーが表示され、変更がブロックされること。
5. `Control + Space` でランチャーが起動し、`Esc` で記録キャンセルができることを確認する。
