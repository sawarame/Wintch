# クイックスタート・検証ガイド (Quickstart): ランチャーおよびリスト型スイッチャーのスクロール追従

**Feature**: `018-fix-launcher-scroll` | **Date**: 2026-11-17

## 1. 自動テストによる検証

```bash
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test
```

期待される結果：
- 既存の全テストスイートに加え、`SwitcherListRowTests`（統一リスト行構築・ID 一意性・インデックス解決）および `SwitcherListViewTests`（`NSHostingView` + `NSScrollView` による実スクロール位置変化検証）がすべてパスすること。
- `SwitcherListViewTests` では以下を確認する：
  - ランチャー表示中にウィンドウ候補＋アプリ起動候補が最大高さを超える状態で `moveSelection(.down)` を繰り返すと、`NSScrollView.contentView.bounds.origin.y` が増加して下方候補へスクロールすること。
  - アプリ起動候補セクションへ横断移動した場合および末尾から先頭・先頭から末尾へ循環移動した場合にも、`bounds.origin.y` が適切に追従すること。
  - 通常スイッチャー（リスト型）表示中に多数ウィンドウが存在する場合も、同様に選択移動へスクロール追従すること。

## 2. `.app` バンドルビルドおよび手動動作確認

```bash
./scripts/build-app.sh
open .build/Wintch.app
```

1. 多数のウィンドウを開いた状態（またはウィンドウ＋検索に一致する多数のアプリ候補が存在する状態）で `Option + Space` を押し、検索ランチャーを表示する。
2. リスト右端に縦スクロールバーが表示されている状態で、`↓` キーを連続して押し下げる。
3. 初期表示領域の下端を超える位置にあるウィンドウ候補や「アプリを起動」配下のアプリ候補へ選択が移ると、リストが自動スクロールし選択行のハイライトが常に視認できることを確認する。
4. `↑` キーで上へ戻る操作、末尾⇔先頭の循環移動、キーワード入力による再絞り込みを行い、選択行とスクロール位置が常に一致していることを確認する。
5. 通常スイッチャー（リスト型：`Option + Tab`）でも多数ウィンドウの移動時に自動スクロール追従することを確認する。
